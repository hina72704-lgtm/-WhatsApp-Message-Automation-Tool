# WhatsApp Message Automation Tool

A powerful Python-based tool for automating WhatsApp messages, supporting single and bulk messaging, templates, scheduling, and comprehensive logging.

## Features

✅ **Send Single Messages** - Quick message sending to individual contacts  
✅ **Bulk Messaging** - Send personalized messages to multiple contacts via CSV/JSON  
✅ **Message Templates** - Create reusable templates with dynamic variables  
✅ **Scheduling** - Schedule messages for future delivery  
✅ **Logging System** - Track all messages with status and timestamps  
✅ **Preview Before Sending** - Review messages before delivery  
✅ **Duplicate Prevention** - Avoid sending duplicate messages  
✅ **Error Handling** - Robust error handling for network issues and invalid numbers  

## Installation

### Prerequisites

- Python 3.7 or higher
- WhatsApp Web account (must be logged in)
